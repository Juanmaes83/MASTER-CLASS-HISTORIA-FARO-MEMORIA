# MASTERCLASS LAB NOTES — THE LAST LIGHTHOUSE

## Why this project exists

The Lighthouse is the control experiment for the methodology. If the same production logic can create a world that is visually, materially and narratively unrelated to Kyoto/Kage, then the methodology is portable rather than stylistically imitative.

## World Bible v0.1

### Narrative metaphor
**Light as orientation; memory as afterlight.**

### Visual contradiction
Cold Atlantic exterior vs warm human/mechanical interior.

### Palette
- near-black ocean / sky
- chalk lighthouse white
- oxidized iron brown
- sea-glass green
- sodium amber
- dawn pearl

### Material logic
Materials must show cause and history:
- salt leaves crystalline residue
- wet iron darkens and oxidizes
- brass wears on touch points
- Fresnel glass shows fine scratches and condensation
- painted masonry stains vertically from rain

### Camera logic
- Coast: distant, patient, architectural
- Keeper: intimate, low-energy, observational
- Machine: closer, circular, mechanically precise
- Beam: camera stabilizes while light becomes motion
- Afterlight: opens back out to distance

### Motion rules
Allowed:
- slow camera interpolation
- fog/salt drift
- low-frequency ocean movement
- mechanical rotation
- word reveals
- subtle image breathing

Forbidden:
- bounce
- elastic UI
- neon glow
- decorative particle explosions
- arbitrary perspective tilt
- scroll-jacking that harms reading

## Vertical Slice: Scene 03 — The Machine

### Narrative job
Reveal the mechanism that converts an ordinary lamp into a coded geographic signal.

### Hybrid compositor
- Generated image plate: material richness and real-world optical complexity
- Three.js: live Fresnel abstraction, rotation, beacon direction and atmosphere
- HTML/CSS: technical annotations and editorial narrative
- Scroll: progression of signal output

### Approval criteria
1. Reads as premium before the user understands the tech.
2. Glass/brass/iron feel materially distinct.
3. The beam is restrained and functional.
4. UI behaves like instrumentation, not dashboard SaaS.
5. Mobile keeps the narrative even if 3D detail is reduced.
